# Flocus-Improved
### 🎯 Flocus – Description

**Focus Tracker** is a productivity-based Chrome extension designed to help users improve their focus, manage study time, and reduce distractions while browsing the internet. It provides a simple Pomodoro timer, daily focus goals, productivity tracking, website usage monitoring, and a study task manager in one place.

The extension allows users to set a daily focus goal, track the amount of time spent on different websites, complete study tasks, and monitor their productivity score. The Pomodoro timer helps users follow focused work sessions followed by short breaks.

By providing clear information about browsing habits and study progress, **Focus Tracker** encourages users to develop better time-management habits and maintain a more productive daily routine.
